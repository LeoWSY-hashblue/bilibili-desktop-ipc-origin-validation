# Bilibili Desktop IPC sender URL allowlist bypass (sanitized advisory)

This repository hosts the **sanitized public advisory** for a Bilibili Desktop
vulnerability. It contains no exploit code, no PoC, no attacker infrastructure
details, and no working reproduction steps.

The full private technical report, PoC video, and reproduction materials are
held by the reporter and are available on request to MITRE CNA-LR or Bilibili
security under responsible-disclosure handling rules.

## Contents

- [`advisory.md`](./advisory.md) — sanitized public advisory (CVSS, CWE,
  affected versions, high-level impact, remediation guidance, disclosure
  timeline)
